This project applies machine learning techniques to classify drug types based on patient data such as age, sex, blood pressure, and cholesterol. Multiple classification models including Logistic Regression, Decision Tree, Random Forest, KNN, SVM, and Naive Bayes were implemented and compared.

Model performance was evaluated using accuracy, precision, recall, F1-score, and confusion matrix. Results show that Decision Tree and Random Forest achieved the highest accuracy, making them the best-performing models for this dataset.
